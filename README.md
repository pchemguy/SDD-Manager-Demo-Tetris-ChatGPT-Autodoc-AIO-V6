# Browser Tetris

A browser-based Tetris project with a playable-classic-first delivery target. The complete intended scope includes modern play, a penetrator bonus, configurable assistance, cookie/URL settings persistence, a session leaderboard and manual JSON/SQLite result files.

The project is in document preparation. No playable build is available yet. Read the accepted [PROJECT brief](docs/dev/PROJECT.md), [preparation record](docs/dev/DOCS_PREPARATION.md) and [workflow handoff](docs/dev/HANDOFF.md). The user accepted the brief and its presented gameplay and technology decisions; detailed design, specification, delivery plan and the unchecked [implementation task list](docs/dev/TASKS.md) are available. Per-document reviews are retained; whole-package QC and implementation remain pending.

See [SDD Manager usage](SDD-MANAGER.md) and the [AI-assisted development disclosure](AI_DISCLOSURE.md). Development follows the [project instructions](AGENTS.md) and [browser development policy](BROWSER_DEV_POLICY.md).
